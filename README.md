# work-location-decentralization
Code and results for “Quantification of the Many Benefits of Work Location Decentralization”: survey analysis of commute time and well-being, plus traffic-aware Google Maps simulation of satellite offices in Chaguanas, San Fernando and Arima (Trinidad and Tobago).

How to run it

Upload survey.csv to the notebook.

Create an outputs/ folder and put these four files in it:
* api_samples_offices.csv
* geocode_qa.csv
* respondent_level_results.csv
* relocation_coding_sheet_for_coder2_filled.csv

Run all cells.
